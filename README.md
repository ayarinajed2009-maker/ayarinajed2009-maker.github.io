# Najed Ayari — Personal Portfolio

A simple, responsive portfolio website introducing ME (Najed Ayari), a student and aspiring developer from Tunisia.

## About the site

The homepage includes a short introduction, an About section, and links to GitHub and the projects page. The design uses plain HTML and CSS, with no build tools or frameworks required.

## Preview locally

Open `index.html` in a web browser. You can also use a local development server, such as the **Live Server** extension in Visual Studio Code.

## Customize

- Edit the page content and links in `index.html`.
- Update the colors, layout, and responsive styles in `style.css`.
- Update `Projects.html` to add or edit the projects linked from the navigation.

## Publish with GitHub Pages

This repository can be published as a GitHub Pages site:

1. Open the repository’s **Settings** on GitHub.
2. Select **Pages**.
3. Choose the `main` branch and the root (`/`) folder as the source, then save.
4. Open the published URL shown in the Pages settings.
